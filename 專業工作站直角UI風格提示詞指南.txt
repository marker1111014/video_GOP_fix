  專業影音工作站風格 (Professional Studio / NLE Workbench UI) 介面設計提示詞與規範指南

一、 此風格的正式行業名稱 (Style Designations)
----------------------------------------------------------------------------------------
在軟體與 UI/UX 設計領域中，這種風格有以下幾種權威通稱：
1. 【主要名稱】：專業影音後製工作站風 (Professional NLE / Dark Studio Workbench UI)
   - 代表經典軟體：DaVinci Resolve（達芬奇）、Adobe Premiere Pro、Blender 4、Reaper、Ableton Live。
2. 【設計流派名稱】：直角現代實用主義 / 瑞士理性暗色風 (Modern Rectilinear Utility / Swiss Minimalist Dark)
   - 核心哲學：承襲包浩斯（Bauhaus）「形隨機能 (Form Follows Function)」原則，零多餘裝飾、極致俐落。
3. 【軟體工程名稱】：專業生產力與工控儀表板 (Technical Desktop & Console UI)
   - 代表軟體：JetBrains IDE (Fleet / Dark Modern)、VS Code Dark Modern、Bloomberg Terminal。

----------------------------------------------------------------------------------------
二、 核心設計準則 (Golden Rules & Visual Principles)
----------------------------------------------------------------------------------------
若要重現或延續這種專業沉穩的高質感介面，必須嚴格遵守以下 5 大硬性準則：

1. 【全直角禁令 (The 0px Radius Rule)】
   - 規則：介面中所有元件（視窗、面板、按鈕、表格、進度條、輸入框、滑桿、選單、彈窗）的圓角半徑一律強制為 0px。
   - 關鍵字：`border-radius: 0px !important;`、Sharp rectangular edges、No rounded corners。

2. 【零 Emoji 與零花俏圖示 (Zero Emojis / Text Bracket Tags)】
   - 規則：絕對不使用任何彩色 Emoji（如 🎬、🚀、🔥、🔴、⚙️ 等），避免玩具感或廉價感。
   - 狀態標記方式：統一使用簡練的方括號等寬文字標籤或工業標準詞：
     * 範例：`[就緒]`、`[分析中]`、`[已完成]`、`[失敗]`、`[高風險] 嚴重卡頓`、`[TS格式]`。

3. 【霧面深炭灰色彩系統 (Matte Dark Charcoal Palette)】
   - 規則：禁止高飽和彩色背景、禁止任何漸層色（No Gradients），統一採用高階霧面純色：
     * 主背景底色 (App Background)    : `#181818` (沉穩霧面黑，極致抗長時間視覺疲勞)
     * 面板/卡片底色 (Panel/Card)       : `#212121` ~ `#242424` (細微明度層次)
     * 次級/抽屜底色 (Sub-Panel/Drawer): `#1c1c1c`
     * 結構邊框分割線 (Hairline Border) : `1px solid #303030` ~ `#383838` (極細銳利實線)
     * 主要文字 (Primary Text)          : `#d4d4d4` (柔和純淨白灰，對比舒適不刺眼)
     * 次要說明文字 (Secondary Text)    : `#888888` ~ `#777777` (低彩度灰階)
     * 主要聚焦動作鍵 (Primary Accent)  : `#0e639c` (專業工作站深冷藍，Studio Cobalt Blue)
       - Hover: `#1177bb` ｜ Pressed: `#094770`
     * 警示/風險狀態 (Warning / Danger) :
       - 高風險/刪除鍵: 底色 `#2a1d1d`、邊框 `#5a2e2e`、文字 `#e07a7a` (低彩度深磚紅)
       - 輕微延遲/警示: 底色 `#2a2418`、邊框 `#5a4820`、文字 `#fbbf24` (低彩度琥珀暗金)
       - 正常/成功狀態: 底色 `#1c261e`、邊框 `#2a402d`、文字 `#4ade80` (低彩度冷杉綠)

4. 【高資訊密度與結構網格 (High Density & Grid Layout)】
   - 緊湊佈局：適當縮減內距 (padding) 與外距 (margin)，強化每平方公分的有效資訊量。
   - 表格排版：1px 細網格線、交替微對比斑馬紋、緊湊表頭（粗體 11px~12px）。

5. 【平坦矩形進度條與滑桿 (Flat Rectilinear Controls)】
   - 進度條：純平矩形槽體（`#222222`）搭配純平色塊填滿（`#0e639c`），高度 8px~16px，無漸層無圓角。
   - 滑桿：細扁矩形軌道（高 4px）+ 方形矩形滑塊（`12px x 16px`）。
